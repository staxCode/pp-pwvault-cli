# PWVault CLI

Password manager offline para terminal.

## Instalación

```bash
npm install
```

## Ejecutar

### Inicializar vault

```bash
npm run dev init
```

### Agregar credencial

```bash
npm run dev add
```

### Listar servicios

```bash
npm run dev list
```

### Obtener credencial

```bash
npm run dev get github
```

## Build

```bash
npm run build
npm start
```
